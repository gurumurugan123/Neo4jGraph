Simon Game



Overview
Simon Game is a fun and interactive memory game where players repeat an increasingly long sequence of colors and sounds to progress to higher levels.

Features
Challenging Gameplay: Repeat the correct sequence to advance.
Dynamic Levels: The sequence gets longer as you progress.
Color and Sound Feedback: Each button has a unique tone and color flash.
Technologies Used
HTML: Provides the game structure.
CSS: Adds styling to the game interface.
JavaScript: Implements the game logic and interactivity.
How to Play
Start the game by pressing any key.
Watch the sequence of colors carefully.
Click on the buttons to repeat the sequence in the correct order.
With each level, a new color is added to the sequence.
The game ends if you make a mistake.
